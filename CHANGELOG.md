# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-08-22

### Added
- Support for .NET 8.0 and .NET 9.0 (multi-targeting).
- Customizable buffer size.

### Changed
- Default buffer size reduced from 80KB to 64KB.

## [1.0.0] - 2026-08-19

### Added
- Initial release.
- Support for MD5, SHA-1, SHA-256, SHA-384, SHA-512, SHA3-256, SHA3-384 and SHA3-512 algorithms.
- Asynchronous hashing of files and streams.
- Progress reporting and cancellation support.
